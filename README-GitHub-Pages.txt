Daxy's World — version statique pour GitHub Pages

Mise en ligne :
1. Décompressez cette archive sur votre ordinateur.
2. Importez le contenu de ce dossier à la racine d'un dépôt GitHub (index.html doit être à la racine).
3. Dans le dépôt, ouvrez Settings > Pages.
4. Sous Build and deployment, choisissez Deploy from a branch, puis la branche main et le dossier /(root), et cliquez Save.

Limites de cette version statique :
- Les pages, styles, scripts et images sont servis comme fichiers statiques.
- L'inscription et la connexion sont désactivées ; elles nécessitent un serveur.
- Le forum est une démonstration locale : les messages ne sont ni partagés ni enregistrés.
- Le formulaire de contact prépare un e-mail dans l'application de messagerie du visiteur ; il ne transmet rien automatiquement.

Avant la mise en ligne, vérifiez les coordonnées et le lien d'adresse affichés sur la page d'accueil : le site publié sera public.
